# SavRS — All in One Media Downloader

SavRS is a responsive online media tools website designed for simple, useful and authorized media tasks.

## Features

- YouTube thumbnail preview
- Direct HTTPS file link checker
- Browser-based video/audio to MP3 conversion
- Official Facebook, Instagram and YouTube help links
- Responsive mobile-friendly design
- No account required for starter tools

## Project Files

- `index.html` — Website structure
- `style.css` — Website design
- `app.js` — Tool functionality
- `README.md` — Project documentation

## Run Locally

Open `index.html` in a modern browser with an internet connection.

## Deploy with Cloudflare Pages

1. Connect this GitHub repository to Cloudflare Pages.
2. Select the static website option.
3. Leave the build command empty.
4. Set the output directory to `/`.
5. Deploy the website.

## Important Usage Rules

SavRS is intended for content that users own or are authorized to access and save.

This starter project does not bypass:
- Private accounts
- Login restrictions
- DRM
- Platform access controls
- Copyright protections

Social platforms may restrict downloads. Use their official download and export options.

The direct file tool opens a user-provided HTTPS file link. The file host may block downloads or require authentication.

The MP3 converter processes a selected file in the user's browser. Large files may require significant device memory and processing time.
